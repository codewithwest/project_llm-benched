# v0.4.0 — Reliable Telemetry & Request Operations

## New Features

- **Request outcome telemetry** — captured requests now include model, HTTP status, error message, and token-count source
- **Server-side request filtering** — filter request history by provider, endpoint, model, date range, text search, and success/error status
- **Filtered CSV export** — export the currently visible request set from the Requests tab
- **Health check** — `GET /healthz` returns a lightweight service status response
- **Replay endpoint targeting** — replay uses the original captured endpoint, including `/api/generate` and `/v1/chat/completions`

## Improvements

- Failed and zero-token requests are now retained instead of disappearing from telemetry
- Streaming response flushing is preserved through the tracking response writer
- Captured request and response bodies are limited to 10 MiB to protect memory and storage
- Replay is restricted to registered provider URLs
- Added SQLite indexes for timestamp, endpoint, and model queries
- Request cards and detail views show model, outcome status, and token-source metadata
- Background request refreshes preserve the latest active filters
- Existing benchmark persistence APIs remain backward-compatible while new metadata is stored explicitly

## Bug Fixes

- Fixed request replay returning `405 method not allowed` by avoiding POST requests to the provider root
- Fixed stale polling responses replacing newer filtered Requests results
- Fixed response capture accounting so the stored body is capped without truncating bytes forwarded upstream

## Tests

- Added replay URL construction tests for Ollama and OpenAI-compatible endpoints
- Added persistence and filtering tests for model and outcome metadata
- Added proxy coverage for failed upstream responses and zero-token requests
- Full Go test suite and frontend production build pass

## Compatibility Notes

- Existing SQLite databases are migrated automatically with the new benchmark metadata columns and indexes
- Rebuild the application binary after upgrading so the embedded UI and API changes are included
